# TEJA PALEPU - AI-Powered Web Developer Portfolio

A modern, dark-themed personal portfolio website built with React and Tailwind CSS.

## Features

- **Modern Dark Theme**: Clean, professional design with green accent colors
- **Fully Responsive**: Mobile-first design with hamburger menu
- **Smooth Animations**: Fade-in effects and scroll animations
- **All Sections Complete**: Navbar, Hero, About, Projects, Services, Testimonials, Contact, Footer
- **AI-Powered Branding**: Showcases AI development tools and rapid delivery
- **Ready to Deploy**: Optimized for Vercel deployment

## Sections

1. **Navbar**: Sticky navigation with blur effect and mobile menu
2. **Hero**: Animated background with call-to-action buttons
3. **About**: Two-column layout with bio and skills showcase
4. **Projects**: Grid of project cards with tech tags
5. **Services**: Three service offerings with icons
6. **Testimonials**: Client testimonials with clean card design
7. **Contact**: Contact form and direct links
8. **Footer**: Social links and copyright

## Tech Stack

- **React 18**: Modern React with hooks
- **Tailwind CSS**: Utility-first CSS framework
- **Inter Font**: Modern sans-serif typography
- **Custom Animations**: Smooth scroll and hover effects

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Deployment

This portfolio is optimized for deployment on Vercel:

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Deploy automatically

## Customization

- Update personal information in component files
- Modify colors in `tailwind.config.js`
- Add your actual project details in `Projects.js`
- Update contact links in `Contact.js` and `Footer.js`
- Replace placeholder testimonials with real client feedback
